# Milestones

## Phase 0 — Project Planning & Documentation

### Goal

Complete all planning and design documents before implementation.

### Tasks

* Initialize Git repository.
* Create project documentation.
* Prepare README.
* Define project requirements.
* Identify system features.
* Define user roles.
* Design system architecture.
* Plan database structure.
* Design REST APIs.
* Plan backend folder structure.
* Define project milestones.
* Prepare deployment strategy.

### Deliverables

* Complete `docs/` folder.
* Finalized project design.
* Development roadmap.

---

## Phase 1 — Backend Foundation

### Goal

Set up the backend project and core infrastructure.

### Tasks

* Initialize Django project.
* Configure Django REST Framework.
* Configure PostgreSQL.
* Configure environment variables.
* Configure authentication.
* Create Django apps.
* Configure media and static files.
* Configure Swagger/OpenAPI.
* Set up logging.

### Deliverables

* Running backend server.
* Connected database.
* Project configuration completed.

---
